Enum은 관련 있는 상수들을 하나로 묶어주는 타입이다. 잘 쓰면 코드가 읽기 쉬워지고 실수도 줄어든다.

오늘은 예시를 보면서 Enum 쓰는 법과 좋은 점을 정리해보자.

---

### 1. 예시: 프로그램 상태를 Enum으로 정의하기

프로그램 상태를 Enum으로 정의해두면 상태에 따라 동작을 나누는 코드를 깔끔하게 쓸 수 있다.

```java
public enum ProgramState {
    STARTING,
    RUNNING,
    PAUSED,
    STOPPED
}
```

ProgramState가 Enum이고, STARTING, RUNNING, PAUSED, STOPPED가 각각 프로그램의 상태를 나타내는 상수다.

### 2. Enum을 쓰는 코드

이제 상태에 따라 다르게 동작하는 코드를 써보자.

```java
public class Program {
    private ProgramState state;

    public Program() {
        state = ProgramState.STARTING;
    }

    public void setState(ProgramState state) {
        this.state = state;
        System.out.println("프로그램 상태가 " + state + "(으)로 변경되었습니다.");
    }

    public void performAction() {
        switch (state) {
            case STARTING:
                System.out.println("프로그램을 시작하는 중입니다...");
                break;
            case RUNNING:
                System.out.println("프로그램이 실행 중입니다.");
                break;
            case PAUSED:
                System.out.println("프로그램이 일시 정지되었습니다.");
                break;
            case STOPPED:
                System.out.println("프로그램이 종료되었습니다.");
                break;
            default:
                System.out.println("알 수 없는 상태입니다.");
                break;
        }
    }

    public static void main(String[] args) {
        Program program = new Program();

        program.performAction(); // STARTING 상태에 따른 동작 수행

        program.setState(ProgramState.RUNNING);
        program.performAction(); // RUNNING 상태에 따른 동작 수행

        program.setState(ProgramState.PAUSED);
        program.performAction(); // PAUSED 상태에 따른 동작 수행

        program.setState(ProgramState.STOPPED);
        program.performAction(); // STOPPED 상태에 따른 동작 수행
    }
}
```

### 3. Enum을 쓰면 좋은 점

타입이 안전하다. ProgramState 타입 변수에는 STARTING, RUNNING, PAUSED, STOPPED처럼 정의된 값만 들어갈 수 있으니 엉뚱한 값이 들어갈 일이 없다.

읽기 쉽다. 상태를 숫자나 문자열로 관리하면 그 값이 뭘 뜻하는지 따로 기억해야 하는데, Enum은 이름 자체가 의미다.

고치기 쉽다. 새 상태가 생기면 Enum에 상수 하나 추가하고 switch문에 case 하나 추가하면 끝이다.

switch문과 잘 맞는다. 위 예시처럼 상태별 동작을 switch로 나누면 코드가 짧고 분명해진다.

### 4. Enum에 메서드 추가하기

Enum은 필드와 메서드도 가질 수 있다. 상태마다 메시지를 돌려주는 메서드를 추가해보자.

```java
public enum ProgramState {
    STARTING("프로그램을 시작하는 중입니다..."),
    RUNNING("프로그램이 실행 중입니다."),
    PAUSED("프로그램이 일시 정지되었습니다."),
    STOPPED("프로그램이 종료되었습니다.");

    private String message;

    ProgramState(String message) {
        this.message = message;
    }

    public String getMessage() {
        return message;
    }
}

public class Program {
    private ProgramState state;

    public Program() {
        state = ProgramState.STARTING;
    }

    public void setState(ProgramState state) {
        this.state = state;
        System.out.println("프로그램 상태가 " + state + "(으)로 변경되었습니다.");
    }

    public void performAction() {
        System.out.println(state.getMessage());
    }

    public static void main(String[] args) {
        Program program = new Program();

        program.performAction();

        program.setState(ProgramState.RUNNING);
        program.performAction();

        program.setState(ProgramState.PAUSED);
        program.performAction();

        program.setState(ProgramState.STOPPED);
        program.performAction();
    }
}
```

이제 `performAction()`이 상태마다 다른 메시지를 출력한다. 동작을 Enum 안에 같이 넣어둘 수 있다는 게 Enum의 꽤 큰 장점이다.

---

프로그램 상태, 명령어 목록, 설정 옵션처럼 정해진 값 몇 개 중 하나를 고르는 경우라면 Enum을 써보자.
