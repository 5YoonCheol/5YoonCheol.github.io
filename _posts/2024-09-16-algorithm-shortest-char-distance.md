오늘 포스팅에서는 문자열에서 특정문자와 다른 문자 사이의 가장 짧은 거리를 구하는 방법에 대해서 알아보려고 한다.

예를 들면

"helloworld" 라는 문자열에서 'o' 와 다른 문자 사이의 가장 짧은 거리를 구하는 것이다.

---

### 1. 문자열을 왼쪽에서 오른쪽으로 읽으며 거리 계산

"helloworld" 를 왼쪽에서 오른쪽으로 읽으며 'o'와의 거리를 계산하는 것이다.  
이 때 'o'와의 거리는 왼쪽에서 오른쪽으로 반복하면서 읽는 기준으로 왼쪽에 있는 'o'와의 거리가 되겠다.

### 2. 문자열을 오른쪽에서 왼쪽으로 읽으며 거리 계산

이번에는 반대로 오른쪽에서 왼쪽으로 읽으며 'o'와의 거리를 계산한다.

왼쪽에서의 거리와 오른쪽에서의 거리 중 더 짧은 것이 가까운 거리이다.

---

### 구현

```java
String str = "helloworld";  //문자열
char c = 'o';  //특정 문자
int[] howLong = new int[str.length()]; //특정문자와의 거리를 담아줄 int배열
int len = 10000; //왼쪽 혹은 오른쪽에 특정문자가 보이지 않는 경우 거리 세팅을 위한 초기값 설정

//왼쪽에서 오른쪽
for(int i=0; i<str.length(); i++){
	if(str.charAt(i) == c){ //문자열의 i번째 문자가 변수 c의 값과 같은 경우
   		len = 0;	//문자와 변수 사이의 거리는 0
        howLong[i] = len;	//거리를 담아줄 int배열에 값 수정
    }else{
    	len++;		//문자와 변수 사이의 거리가 1씩 증가해야함
        howLong[i] = len; //배열 값 수정
    }
}

//오른쪽에서 왼쪽
len = 10000; //오른쪽에서 다시 계산하므로 다시 초기화
for(int i=str.length()-1; i>=0; i--){
	if(str.charAt(i) == c){ //문자열의 i번째 문자가 변수 c의 값과 같은 경우
   		len = 0;	//문자와 변수 사이의 거리는 0, 이미 배열에 0이 담겨 있으므로 값 수정할 필요 없음
    }else{
    	len++;		//문자와 변수 사이의 거리가 1씩 증가해야함
        howLong[i] = Math.min(len, howLong[i]); //가까운 거리 = 더 작은 값
    }
}

결과 -> [4, 3, 2, 1, 0, 1, 0, 1, 2, 3]
```
