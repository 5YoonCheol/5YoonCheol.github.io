AWS(Amazon Web Services)는 아마존이 운영하는 클라우드 컴퓨팅 플랫폼이다. 서버, 스토리지부터 각종 부가 서비스까지 제공하고, 전 세계 수많은 회사와 개발자가 여기서 애플리케이션을 만들고 운영한다.

이번엔 AWS의 기본 개념과 자주 쓰는 서비스, 장단점을 정리해보자.

---

### 1. AWS란

컴퓨팅 파워, 스토리지, 데이터베이스, 네트워크 같은 인프라 자원을 인터넷으로 빌려주는 클라우드 플랫폼이다. 요금은 쓴 만큼 내는 종량제다. 덕분에 서버를 직접 사거나 관리하지 않고도 AWS 인프라 위에서 애플리케이션을 만들고 키울 수 있다.

---

### 2. 자주 쓰는 서비스

서비스가 수백 개나 되지만, 그중 많이 쓰는 것들만 추려봤다.

#### EC2 (Elastic Compute Cloud)

가상 서버를 빌려주는 서비스다. 원하는 OS와 사양을 골라 인스턴스를 만들고 배포하면 된다. 필요에 따라 서버 수를 늘리고 줄일 수 있어서 확장하기 좋다. 웹 서버를 EC2에 올려 두고 트래픽에 맞춰 대수를 조절하는 식으로 쓴다.

#### S3 (Simple Storage Service)

파일 저장소다. 이미지, 동영상, 문서 같은 파일을 안전하게 저장할 수 있다. 데이터가 잘 안 날아가고 용량도 얼마든지 늘릴 수 있으며, 쓴 만큼 돈을 낸다. 사용자 프로필 이미지나 백업 파일을 넣어 두는 용도로 많이 쓴다.

#### RDS (Relational Database Service)

관리형 관계형 DB 서비스다. MySQL, PostgreSQL, MariaDB, Oracle, SQL Server 등을 고를 수 있다. 백업, 복제, 장애 조치를 알아서 해줘서 DB 관리가 편하다. 사용자 데이터나 거래 데이터를 저장하는 데 쓴다.

#### Lambda

서버리스 컴퓨팅 서비스다. 특정 이벤트가 생기면 코드가 실행된다. 서버를 관리할 필요가 없고, 코드가 도는 동안만 비용이 나간다. 예를 들어 S3에 파일이 올라오면 자동으로 이미지 크기를 줄이는 함수를 만들 수 있다.

#### VPC (Virtual Private Cloud)

내가 정의한 네트워크 안에 자원을 배치할 수 있게 해주는 가상 네트워크다. 보안 그룹과 네트워크 ACL로 보안을 강화할 수 있다. 내부에서만 접근하는 DB 서버를 VPC 안에 두고 외부 접근을 막는 식으로 쓴다.

#### CloudFront

CDN(콘텐츠 전송 네트워크) 서비스다. 전 세계에 흩어진 엣지 로케이션을 통해 사용자가 가까운 곳에서 콘텐츠를 받게 해준다. 웹사이트의 정적 파일, 동영상, 이미지처럼 큰 데이터를 빠르게 보낼 때 쓴다.

---

### 3. 장점

- 확장성: 서버와 스토리지를 필요할 때 늘리고 줄일 수 있어서 트래픽 변화에 대응하기 쉽다.
- 글로벌 인프라: 전 세계 리전과 가용 영역을 활용해서 글로벌 서비스를 운영할 수 있고, 사용자와 가까운 곳에서 응답하니 빠르다.
- 비용: 하드웨어 구매와 유지보수 비용이 들지 않고, 쓴 만큼만 낸다.
- 보안과 컴플라이언스: 보안 기능이 많고 HIPAA, GDPR, SOC 같은 규정을 준수하기 때문에 보안 요구가 높은 업계에서도 쓸 수 있다.
- 서비스 간 연동: 서비스들이 API로 서로 연결돼서 조합해 쓰기 좋다.

### 4. 단점

- 어렵다: 기능도 설정도 많아서 처음엔 막막하다. 제대로 구성하려면 공부할 게 많다.
- 비용 관리: 서비스마다 종량제로 청구되다 보니 신경 안 쓰면 예상 못 한 요금이 나올 수 있다. 비용 관리를 적극적으로 해야 한다.
- 벤더 종속: AWS에 데이터를 쌓아 두면 다른 클라우드로 옮기기 어렵다(vendor lock-in). 옮기려면 시간과 비용이 많이 든다.
- 지원 비용: 무료 지원도 있지만, 빠르고 구체적인 기술 지원을 받으려면 유료 지원 플랜을 사야 한다.

---

### 5. 누가 쓰나

- 스타트업: 빠르게 만들어서 내놓아야 하니 초기 인프라 비용을 아끼고 필요할 때마다 키우는 식으로 쓴다.
- 대기업: 대량의 데이터를 관리하고, 클라우드 기반 머신러닝이나 빅데이터 분석 서비스로 인사이트를 얻는다.
- 게임: 게임 서버, DB, 사용자 인증 등을 AWS로 구성하고 전 세계 사용자에게 빠르게 서비스한다.
