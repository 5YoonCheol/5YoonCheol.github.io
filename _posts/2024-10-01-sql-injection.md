SQL Injection(인젝션)은 웹 애플리케이션의 보안 취약점을 악용하여, 악의적인 사용자가 SQL 쿼리를 조작함으로써 데이터베이스에 불법적으로 접근하거나 조작하는 공격 방법이다.

주로 사용자가 입력하는 데이터를 제대로 검증하지 않고 SQL 쿼리에 직접 포함시킬 때 발생힌다. 이로 인해 공격자는 원래 의도된 쿼리 외에 추가적인 명령을 실행할 수 있다.

---

### SQL Injection의 동작 원리

SQL Injection은 주로 웹 애플리케이션이 **사용자 입력을 안전하게 처리하지 않는 경우**에 발생한다.

예를 들어, 로그인 페이지에서 사용자 아이디와 비밀번호를 확인하는 SQL 쿼리가 있다고 가정해 보자.

```sql
SELECT * FROM users WHERE username = 'user' AND password = 'pass';
```

이 쿼리는 'user'라는 사용자와 'pass'라는 비밀번호가 일치하는지 확인하는 역할을 합니다.

하지만 만약 사용자가 아래와 같이 입력한다면

- **username**: ' OR 1=1 --
- **password**: 무시됨

위의 입력값을 쿼리에 그대로 포함시키면 다음과 같은 쿼리가 생성된다.

```sql
SELECT * FROM users WHERE username = '' OR 1=1 -- ' AND password = '무시됨';
```

이 쿼리는 OR 1=1 부분으로 인해 항상 참이 되어, 비밀번호 확인 없이 전체 사용자 목록을 반환하게 된다.

'--'는 SQL에서 주석 처리를 의미하여 뒤의 내용을 무시하게 만든다.

결과적으로, 비밀번호 확인 없이 로그인하거나, 데이터베이스에 접근할 수 있게 된다.

---

### SQL Injection 공격의 유형

SQL Injection에는 여러 가지 유형이 있다.

1. **In-band SQL Injection (동일 채널 SQL 인젝션)**:
   - 공격자가 데이터베이스에서 직접 데이터를 빼내거나 수정할 수 있는 가장 일반적인 형태이다. 예를 들어, 공격자가 쿼리 결과를 웹 페이지로 직접 확인할 수 있는 경우이다.
2. **Blind SQL Injection (블라인드 SQL 인젝션)**:
   - 응답으로 데이터를 직접 얻을 수는 없지만, 조건문을 이용해 데이터베이스의 상태를 확인하는 방식이다. 예를 들어, 참/거짓으로 응답이 달라지도록 쿼리를 설계해 원하는 정보를 추론할 수 있다.
3. **Out-of-band SQL Injection (채널 분리 SQL 인젝션)**:
   - 웹 애플리케이션의 응답이 아닌 다른 방식(예: 이메일 또는 외부 서버로의 요청)을 통해 공격자가 결과를 얻는 방식이다. 이 방법은 공격 대상의 네트워크 설정에 따라 사용된다.

---

### SQL Injection 방지 방법

SQL Injection 공격을 방지하기 위해서는 여러 보안 기법을 적용해야 한다.

1. **Prepared Statements**
   - SQL 쿼리에 사용자 입력값을 직접 포함시키지 않고, 쿼리를 미리 준비한 후 변수로 값을 전달하는 방식이다. 예를 들어, PHP나 Java에서 **Prepared Statements**를 사용하면, 쿼리와 데이터를 분리하여 인젝션 공격을 방지할 수 있다.
2. **ORM(Object-Relational Mapping)**:
   - ORM을 사용하면 데이터베이스 쿼리가 자동으로 안전하게 처리되므로 직접적인 SQL 쿼리 작성이 필요 없게 되어 인젝션 위험이 줄어든다. 예를 들어, **Django ORM**이나 **Hibernate**와 같은 도구가 있다.
3. **입력값 검증**:
   - 사용자가 입력하는 데이터는 반드시 필터링하거나 검증해야 한다. 예를 들어, 이메일이나 숫자 등의 값에 대해서는 정규식을 사용해 형식을 검증할 수 있다.
4. **최소 권한 원칙**:
   - 데이터베이스 사용자의 권한을 최소한으로 설정하여, 만약 공격이 발생하더라도 데이터베이스 전체에 악영향을 미치지 않도록 해야 한다.
5. **WAF(Web Application Firewall)**:
   - WAF를 통해 SQL Injection 공격 패턴을 실시간으로 감지하고 차단할 수 있다.
