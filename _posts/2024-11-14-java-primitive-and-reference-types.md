Java의 데이터 타입은 크게 기본형(Primitive Type)과 참조형(Reference Type)으로 나뉜다.

둘은 메모리에 저장되는 방식과 성질이 다르고, 그래서 쓰는 방법도 다르다.

---

### 1. 기본형 (Primitive Type)

가장 기본적인 데이터 타입으로, 변수에 값이 바로 저장된다. 참조 없이 값 자체를 메모리에 담고, 타입마다 크기가 정해져 있다. 기본형 값은 변경 불가능(immutable)해서 값이 바뀌면 새로 할당된다.

#### 기본형 타입 종류

Java에는 기본형이 8가지 있다.

- 정수형
  - byte: 1바이트, -128 ~ 127 범위의 정수.
  - short: 2바이트, -32,768 ~ 32,767 범위의 정수.
  - int: 4바이트, -2^31 ~ 2^31-1 범위의 정수. 가장 많이 쓰는 정수형이다.
  - long: 8바이트, -2^63 ~ 2^63-1 범위의 정수. 큰 수를 다룰 때 쓰고, 리터럴 뒤에 L을 붙인다.
- 실수형
  - float: 4바이트 단정밀도 실수. 소수점 이하 약 7자리까지 표현하고, 리터럴 뒤에 F를 붙인다.
  - double: 8바이트 배정밀도 실수. 소수점 이하 약 15자리까지 표현한다. 실수는 보통 이걸 쓴다.
- 문자형
  - char: 2바이트 유니코드 문자. 문자 하나를 작은따옴표('A')로 감싸서 쓴다.
- 논리형
  - boolean: true 또는 false 두 값만 가진다.

```
int age = 25;        // 정수형
double price = 19.99; // 실수형
char grade = 'A';     // 문자형
boolean isStudent = true; // 논리형
```

기본형은 값을 직접 스택 메모리에 저장하기 때문에 접근이 빠르다.

---

### 2. 참조형 (Reference Type)

참조형은 객체의 주소값(참조값)을 저장한다. 실제 데이터는 힙 메모리에 있고, 변수는 그 객체가 있는 위치를 가리킨다.

클래스, 배열, 인터페이스 등이 참조형이다.

#### 참조형 타입 종류

클래스 (Class): Java에서 다루는 데이터 대부분은 클래스의 인스턴스다. 클래스로 사용자 정의 객체를 만들 수 있고, 메서드와 속성을 가진다.

```
String name = "Alice";  // String 클래스는 Java의 참조형
```

배열 (Array): 같은 타입의 값 여러 개를 하나로 묶어 저장한다. Java에서는 배열도 참조형이다.

```
int[] numbers = {1, 2, 3, 4}; // 정수형 배열
```

인터페이스 (Interface): 메서드들의 집합으로, 구현하는 클래스가 그 메서드를 반드시 정의하게 한다. 인터페이스 타입으로도 변수를 선언할 수 있다.

```
List<String> list = new ArrayList<>(); // List 인터페이스를 참조하는 ArrayList 객체
```

참조형 변수는 아무 객체도 할당하지 않으면 `null`을 가질 수 있다. 어떤 객체도 가리키지 않는 상태라는 뜻이다.

```
String greeting = "Hello"; // String 클래스는 참조형
int[] scores = {90, 85, 100}; // 배열도 참조형
```

---

### 기본형과 참조형의 차이

| 비교 항목 | 기본형 (Primitive Type) | 참조형 (Reference Type) |
| --- | --- | --- |
| 저장 방식 | 값 자체를 메모리에 저장 | 객체의 주소(참조값)를 저장 |
| 메모리 할당 위치 | 스택 메모리 | 힙 메모리 |
| 초기 값 | 각 타입별 기본 값 (int는 0, boolean은 false 등) | null (어느 객체도 참조하지 않는 상태) |
| 불변성 | 값 자체를 저장하며 불변 (값을 바꾸면 새로 할당) | 객체 내의 값은 변경 가능 (가리키는 객체의 속성 값을 변경 가능) |
| 사용 목적 | 간단한 데이터 저장에 적합 | 객체, 데이터 구조 저장에 적합 |
| 예시 | int age = 25; | String name = "Alice"; |

### 예시로 보는 차이

```
public class Main {
    public static void main(String[] args) {
        int x = 10;            // 기본형 변수
        int y = x;             // 값 복사
        y = 20;
        System.out.println("x: " + x); // x는 10 (기본형은 값 자체를 복사하므로 영향 없음)

        int[] arr1 = {1, 2, 3};  // 참조형 변수 (배열)
        int[] arr2 = arr1;       // 참조값을 복사
        arr2[0] = 10;
        System.out.println("arr1[0]: " + arr1[0]); // arr1[0]은 10 (참조형은 같은 객체를 가리키므로 영향 있음)
    }
}
```

`x`와 `y`는 값 자체가 복사되기 때문에 `y`를 바꿔도 `x`는 그대로다.

반면 `arr1`과 `arr2`는 같은 배열 객체를 가리키고 있어서, `arr2`의 요소를 바꾸면 `arr1`도 같이 바뀐다.
