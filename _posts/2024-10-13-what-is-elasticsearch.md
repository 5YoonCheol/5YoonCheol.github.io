Elasticsearch는 분산형 검색/분석 엔진이다. 데이터가 아주 많아도 실시간으로 검색하고 분석할 수 있다는 게 강점이다. 오픈소스로 시작했고, 지금은 빅데이터, 로그 분석, 실시간 검색이 필요한 곳에서 많이 쓴다.

이번엔 Elasticsearch가 뭔지, 어떤 특징이 있고 어디에 쓰는지 정리해보자.

---

### 1. Elasticsearch란

Apache Lucene을 기반으로 만들어졌고, 데이터를 JSON 문서 형태로 저장하고 색인(indexing)한다. 여러 소스에서 데이터를 받아 인덱스에 넣어 두면 바로 검색할 수 있다. 접근은 RESTful API로 해서, HTTP 요청만으로 검색과 분석을 할 수 있다.

---

### 2. 특징

#### 분산 구조

여러 서버(노드)가 모여 하나의 클러스터를 이루고 데이터를 나눠 저장하고 처리한다.

데이터는 인덱스라는 논리적인 묶음에 들어가고, 인덱스는 다시 샤드(Shard)로 쪼개져서 여러 노드에 흩어져 저장된다. 이렇게 나눠 담기 때문에 확장하기 쉽고, 노드 하나가 죽어도 버틴다.

#### 검색 기능

정확히 일치하는 검색은 물론이고 유사도 검색, 필터링, 정렬까지 된다. 텍스트 분석기로 데이터를 검색하기 좋게 가공해 두기 때문에 키워드나 문구로 빠르고 정확하게 찾을 수 있다. 전체 텍스트 검색과 여러 필드를 동시에 보는 검색도 가능하다.

#### 실시간 처리

데이터가 들어오면 거의 바로 검색할 수 있다. 실시간 로그 분석, 이벤트 모니터링, 스트리밍 데이터 처리에 잘 맞는 이유다.

#### 집계 기능

데이터를 요약하고 집계하는 기능이 좋다. 예를 들어 특정 기간의 평균, 최대값, 최소값을 바로 계산할 수 있어서 통계를 내거나 시각화할 때 유용하다.

#### 수평 확장

서버 성능을 올리는 수직 확장도 되지만, 서버를 추가하는 수평 확장이 된다는 게 핵심이다. 데이터나 트래픽이 늘면 노드를 붙이면 된다.

#### RESTful API

생성, 조회, 수정, 삭제(CRUD)와 검색을 전부 REST API로 한다. HTTP 요청만 보내면 되니 애플리케이션에 붙이기 쉽다.

---

### 3. 구조

RDB에 빗대어 보면 이해가 쉽다.

- 인덱스(Index): RDB의 데이터베이스쯤 되는 개념으로, 비슷한 데이터의 묶음이다. 예를 들어 회사 직원 데이터 전체를 인덱스 하나로 만들 수 있다.
- 도큐먼트(Document): 인덱스 안에 저장되는 데이터 한 건이다. JSON으로 표현되고, 직원 한 명의 정보가 도큐먼트 하나가 된다.
- 샤드(Shard): 인덱스를 쪼갠 단위다. 샤드들이 클러스터의 여러 노드에 나눠 저장된다.
- 레플리카(Replica): 샤드의 복제본이다. 가용성과 성능을 위해 다른 노드에 복사해 둔다.

---

### 4. 장점

- 빠르다: 색인 구조 덕분에 데이터가 많아도 검색이 빠르다. 로그 분석이나 실시간 검색에서 특히 힘을 발휘한다.
- 확장성: 샤드와 레플리카로 데이터를 나눠 저장하고 처리하니 데이터가 늘어도 성능이 유지된다.
- 붙이기 쉽다: REST API라서 언어나 플랫폼 상관없이 쉽게 연동된다.
- 분석 기능: 집계, 필터링, 정렬로 다양하게 분석할 수 있어서 통계나 시각화에 잘 맞는다.

### 5. 단점

- 수정 비용: 색인된 상태로 저장되다 보니 데이터를 업데이트할 때 오버헤드가 있다. 수정이 잦으면 성능이 떨어질 수 있다.
- 메모리를 많이 쓴다: 인덱스와 캐시를 메모리에 올려 두기 때문에 빠른 대신 메모리 사용량이 크다. 데이터가 많으면 메모리가 모자랄 수 있다.
- 운영이 복잡하다: 노드 여러 대로 이뤄진 분산 시스템이라 클러스터 관리가 쉽지 않다.

---

### 6. 어디에 쓰나

- 로그/이벤트 분석: 실시간 로그를 모아서 분석한다. ELK 스택(Elasticsearch, Logstash, Kibana)의 한 축이고, 웹사이트 트래픽 모니터링이나 애플리케이션 성능 분석에 쓴다.
- 검색 엔진: 대량의 문서에서 키워드로 빠르게 찾아야 하는 곳. 쇼핑몰 상품 검색이나 SNS 게시글 검색 같은 기능이다.
- 추천 시스템: 유사도 검색을 이용해서 사용자가 좋아할 만한 영화나 음악을 추천하는 데 쓸 수 있다.
- 데이터 분석과 시각화: 집계 기능으로 실시간 분석을 하고, Kibana와 연결해서 시각화한다.
