### 1. 프로세스 (Process)

프로세스는 **컴퓨터에서 실행 중인 프로그램의 인스턴스**를 의미한다. 즉, 특정 프로그램을 실행하게 되면 운영체제(OS)가 메모리 공간과 시스템 자원을 할당하여 독립적인 작업 단위를 형성하는데, 이를 프로세스라고 한다.

#### 주요 특징

- **독립적인 메모리 공간**: 프로세스는 실행에 필요한 독립적인 메모리 공간(코드, 데이터, 힙, 스택)을 가지고 있으며, 각 프로세스는 다른 프로세스와 메모리를 공유하지 않는다.
- **운영체제에 의해 관리됨**: 운영체제는 각 프로세스의 상태, CPU 할당, 메모리 관리 등을 관리하며, 프로세스 간에 자원 접근을 조율한다.
- **비교적 높은 자원 소모**: 프로세스는 독립적인 메모리 공간을 가지기 때문에, 새로운 프로세스를 생성할 때 자원을 많이 소모한다.
- **다중 프로세싱**: 여러 프로세스를 동시에 실행하는 다중 프로세싱이 가능하며, 각 프로세스는 서로 독립적으로 동작하여 다른 프로세스에 영향을 주지 않는다.

#### 프로세스의 구성 요소

- **코드 영역 (Code Segment)**: 실행할 프로그램의 코드가 저장되는 영역이다.
- **데이터 영역 (Data Segment)**: 전역 변수와 정적 변수가 저장된다.
- **힙 영역 (Heap Segment)**: 동적 메모리 할당이 일어나는 영역이다.
- **스택 영역 (Stack Segment)**: 함수 호출과 관련된 지역 변수, 매개변수가 저장된다.

#### 프로세스의 상태

- **생성 (New)**: 프로세스가 생성된 초기 상태이다.
- **준비 (Ready)**: 실행될 준비가 된 상태이다.
- **실행 (Running)**: CPU를 점유하여 실제로 실행 중인 상태이다.
- **대기 (Waiting)**: 자원 대기 또는 I/O 요청으로 인해 잠시 중단된 상태이다.
- **종료 (Terminated)**: 실행이 완료되거나 중단되어 종료된 상태이다.

### 2. 스레드 (Thread)

스레드는 프로세스 내에서 실제 작업을 수행하는 **실행의 단위**. 하나의 프로세스에는 하나 이상의 스레드가 존재할 수 있으며, 이러한 스레드는 프로세스 내의 자원을 공유하면서 동시에 작업을 수행할 수 있다.

#### 주요 특징

- **프로세스의 일부**: 스레드는 프로세스의 자원을 공유하며, 하나의 프로세스 내에서 다수의 스레드가 동시에 실행될 수 있다.
- **가벼운 자원 소모**: 스레드는 독립적인 메모리 공간을 가지지 않기 때문에 프로세스에 비해 상대적으로 가벼우며, 새로운 스레드를 생성하는 것이 더 빠르고 자원을 적게 소모한다.
- **멀티스레딩**: 다중 스레드를 생성하여 병렬 작업을 수행함으로써 성능을 높일 수 있다. 예를 들어 웹 서버는 각 사용자 요청마다 스레드를 생성하여 동시에 다수의 요청을 처리할 수 있다.

#### 스레드의 구성 요소

- **스택**: 각 스레드는 개별 스택을 가지며, 함수 호출과 지역 변수가 이곳에 저장된다.
- **레지스터**: CPU가 작업을 수행하기 위해 사용하는 레지스터 상태는 스레드마다 따로 관리된다.
- **프로그램 카운터**: 각 스레드의 실행 위치를 추적하기 위한 프로그램 카운터를 가지고 있다.

#### 스레드의 장단점

- **장점**: 스레드는 자원을 공유하므로 프로세스보다 메모리와 CPU 자원 소모가 적으며, 데이터 교환이 빠르다.
- **단점**: 자원을 공유하므로 동기화 문제가 발생할 수 있으며, 한 스레드가 오류를 일으키면 프로세스 전체에 영향을 줄 수 있다.

### 3. 프로세스와 스레드의 차이점

| **구분** | **프로세스** | **스레드** |
| --- | --- | --- |
| **메모리** | 독립된 메모리 영역을 가짐 | 같은 프로세스 내에서 메모리 공간을 공유 |
| **자원 소모** | 높은 자원 소모 | 비교적 낮은 자원 소모 |
| **독립성** | 다른 프로세스와 독립적으로 실행됨 | 같은 프로세스의 다른 스레드에 영향을 미칠 수 있음 |
| **오류 영향** | 한 프로세스의 오류는 다른 프로세스에 영향 없음 | 한 스레드의 오류가 프로세스 전체에 영향을 미칠 수 있음 |
| **생성 속도** | 새로운 프로세스 생성 속도가 상대적으로 느림 | 새로운 스레드 생성 속도가 상대적으로 빠름 |

### 4. 활용 예시

- **프로세스 활용**: 여러 프로그램을 동시에 실행할 때, 각각의 프로그램은 별도의 프로세스로 관리된다. 예를 들어, 웹 브라우저와 워드 프로세서를 동시에 실행하면 두 개의 독립된 프로세스로 구분된다.
- **스레드 활용**: 하나의 애플리케이션 내에서 동시에 여러 작업을 수행할 때 사용된다. 예를 들어, 웹 브라우저의 각 탭은 별도의 스레드로 동작하여 동시에 여러 웹 페이지를 로드할 수 있다.
