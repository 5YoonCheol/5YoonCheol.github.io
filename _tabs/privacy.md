## 1. 수집하는 정보

이 블로그는 회원 가입이나 로그인 기능이 없으며, 운영자가 직접 방문자의 개인정보를 요구하거나 저장하지 않습니다. 다만 아래 외부 서비스를 통해 일부 정보가 자동으로 수집될 수 있습니다.

### 방문 통계

- **GoatCounter**(goatcounter.com): 페이지별 조회수와 방문 수를 집계합니다. 쿠키를 사용하지 않으며, IP 주소와 User-Agent를 해시 처리해 개별 방문자를 식별하지 않는 형태로 통계를 냅니다.
- **Abacus**(abacus.jasoncameron.dev): 홈 화면의 방문자 수 카운터에 사용합니다. 하루에 한 번만 세기 위해 브라우저 로컬 저장소에 마지막 방문 날짜만 저장하며, 개인을 식별하는 정보는 전송하지 않습니다.

### 댓글

- 댓글은 **giscus**(giscus.app)를 통해 GitHub Discussions에 저장됩니다. 댓글을 쓰려면 GitHub 계정으로 로그인해야 하며, 이때 수집되는 정보는 [GitHub 개인정보처리방침](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)을 따릅니다. 댓글을 읽기만 할 때는 로그인이 필요 없습니다.

### 광고

- 이 블로그는 **Google AdSense** 광고를 게재할 수 있습니다. Google을 포함한 제3자 광고 제공업체는 쿠키를 사용해 방문자가 이 블로그와 다른 웹사이트를 방문한 기록을 바탕으로 광고를 표시할 수 있습니다.
- Google의 광고 쿠키 사용에 대한 자세한 내용과 맞춤 광고를 해제하는 방법은 [Google 광고 설정](https://adssettings.google.com/)과 [Google 개인정보처리방침](https://policies.google.com/privacy)을 참고해 주세요.

### 문의 메일

- [연락처 페이지]({{ '/contact/' | relative_url }})로 보내 주신 메일의 이름, 이메일 주소, 본문은 답장과 문의 처리 목적으로만 이용하며, 처리가 끝난 뒤에는 보관하지 않습니다.

## 2. 쿠키와 로컬 저장소

- 블로그 자체는 다크 모드 설정처럼 화면 표시에 필요한 값만 브라우저 로컬 저장소에 저장합니다.
- 광고와 댓글 기능에서 사용하는 쿠키는 각 서비스 제공자가 관리하며, 브라우저 설정에서 쿠키를 거부하거나 삭제할 수 있습니다. 쿠키를 거부해도 글을 읽는 데는 문제가 없습니다.

## 3. 정보의 제3자 제공

운영자는 수집된 정보를 제3자에게 판매하거나 제공하지 않습니다. 위에 안내한 외부 서비스가 처리하는 정보는 각 서비스의 개인정보처리방침에 따릅니다.

## 4. 외부 링크

블로그 글에는 다른 웹사이트로 연결되는 링크가 있습니다. 링크된 사이트의 개인정보 처리에 대해서는 이 방침이 적용되지 않으며, 해당 사이트의 방침을 확인해 주세요.

## 5. 방침의 변경

이 방침은 법령이나 블로그 운영 방식이 바뀌면 수정될 수 있으며, 변경 내용은 이 페이지에 게시합니다.
