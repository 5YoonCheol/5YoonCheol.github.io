안녕하세요. Java 백엔드 개발자 **윤철**입니다.

Java와 Spring으로 서버를 만든 지 5년이 되었습니다. 낮에는 서비스 코드를 만들고 운영하고, 밤에는 그날 부딪힌 문제와 배운 것을 이 블로그에 남깁니다. 블로그 이름 *새벽 2시의 커밋*은 그렇게 잠들기 전 마지막 커밋처럼 기록을 남기자는 뜻에서 지었습니다.

## 주력 분야

- **Spring 백엔드**: Spring Boot, Spring Data JPA, 트랜잭션과 영속성 컨텍스트, 실무에서 자주 밟는 함정 정리
- **데이터베이스**: MySQL 인덱스와 실행 계획, 격리 수준, 복제 구성, 쿼리 튜닝
- **DevOps**: Docker, CI/CD 파이프라인, 리눅스 서버 운영과 배포 자동화
- **기본기**: 자료구조와 알고리즘, 객체 지향 설계, 네트워크와 운영체제

## 이 블로그에 쓰는 글

- **실무 함정 정리**: 문서만 읽어서는 알기 어려운, 직접 겪고 나서야 이해한 동작을 재현 가능한 예제와 함께 정리합니다. 예: [@Transactional이 동작하지 않는 경우 정리]({{ '/posts/spring-transactional-pitfalls/' | relative_url }})
- **개념 정리**: 면접이나 코드리뷰에서 다시 꺼내 보려고 쓴 짧은 개념 글입니다. 2024년에 몰아서 쓴 글이 많고, 지금은 하나씩 다시 읽으며 내용을 보강하고 있습니다.
- **시리즈**: Spring 실무 함정, MySQL 실무 튜닝처럼 한 주제를 여러 편으로 이어 쓰는 글을 준비하고 있습니다.

글에 나오는 코드는 모두 설명을 위해 새로 만든 예제이며, 특정 회사나 서비스의 코드가 아닙니다.
