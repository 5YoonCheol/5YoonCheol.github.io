# 5yooncheol.github.io

윤철의 개발 블로그입니다. [Jekyll](https://jekyllrb.com/)과 [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) 테마로 만들었고, `main` 브랜치에 푸시하면 GitHub Actions가 빌드해서 GitHub Pages에 배포합니다.

- 블로그: https://5yooncheol.github.io
- 글 위치: `_posts/YYYY-MM-DD-slug.md`

로컬 미리보기:

```bash
bundle install
bundle exec jekyll serve
```
